# oxvxoro

개인 개발 공부 및 기록용 사이트입니다.

- Blazor WebAssembly (standalone)
- .NET 10
- GitHub Pages로 배포
- 브라우저 기본 스타일을 최대한 유지

## 기록 작성

`Content/<category>/YYYY-MM-DD-slug.md` 파일을 추가합니다.

예:

```text
Content/csharp/2026-08-18-linq.md
```

규칙:

- 폴더는 한 단계만 category로 사용
- 파일명은 `YYYY-MM-DD-slug.md`
- 첫 번째 `# 제목`을 사이트 제목으로 사용
