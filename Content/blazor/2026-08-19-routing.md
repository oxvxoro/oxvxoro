# Blazor Routing

오늘 Blazor Router를 공부했다.

## @page

Razor component에서 route를 선언한다.

```razor
@page "/example"
```

## catch-all parameter

경로의 나머지 부분을 통째로 받을 수 있다.

```razor
@page "/notes/{*Path}"
```

## 기억할 것

- Router는 앱 assembly에서 `@page` 지시문을 스캔해 route를 등록한다.
- catch-all parameter는 문자열 하나로 전달된다.
